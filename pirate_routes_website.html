Arlong Park — building sweep

Best for a concentrated search through a large compound.

Main building→Adjacent buildings→Optional nearby vault
Work through the main building floor by floor, checking rooms and upper levels.
Move into the nearby buildings and check each area systematically.
Only add the nearby vault if you already have the required key.
When the area is cleared, rotate toward the next safe search area.

Chest positions are not guaranteed to spawn in every match. Skip areas that have already been looted.

Northeast Coast — six-stop shoreline loop

A moving route connecting coastal landmarks.

1 · Northern huts→2 · Offshore island→3 · Coastal stairs→4 · Crab landmark→5 · Boat stop→6 · Inland exit
Search the northern huts, tents and nearby shoreline.
Cross to the small offshore island and check the sandy buried-treasure mounds.
Return to the coast and search the building around the stairs.
Continue along the shore to the crab-shaped landmark and check around it.
Search the boat stop and nearby structures.
Finish by rotating inland or toward the safe zone.

Water crossings and storm movement can make this route slower in some matches.

The Chest — buried treasure sweep

A digging-focused route around the sandy area below Rubber Resort.

Eastern cliff→Sandy mounds→Small islands→Next safe area
Start around the cliff east of The Chest and search nearby chest positions.
Sweep the sandy mounds in one direction so you don't double back.
Check the small sandbars and nearby boats for additional search spots.
When finished, rotate toward the next area that fits the storm.

The number of available chests varies by match. This is a suggested search order, not a guaranteed spawn list.

TOKEN BASICS

How the hunt works

🎁 Random reward

The Pirate Shop Access Token can appear as a rare reward from eligible Treasure Hunt containers. It is not sitting at one permanent map coordinate.

🧭 Why use routes?

Routes help you cover more search locations with less backtracking. More eligible searches mean more opportunities, but luck still decides whether a Token appears.
